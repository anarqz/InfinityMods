# Extra Options - Garage Revving: attribution and scope

Garage engine revving: Arthur (RokkuDayo), part of Extra Options,
https://github.com/RokkuDayo/ForzaHorizon2_ExtraOptions, GPL-3.0.

Nothing is built or packaged here (owner, 2026-11-16): Infinity downloads the author's own Extra Options 0.6.1
release ZIP (`Forza_XB1_Extra_Options_0.6.1-Azimuth.zip`, release `Azimuth_v1.0.4`), checks it by SHA-256 and
installs only the author's `Extra Options - Garage Revving` files from it (`mod.json`, `plugins\EO_GarageEngineRev.dll`
and its `.ini`), each checked by SHA-256, into `<Azimuth>\mods\Forza Horizon 2\extraoptions-garagerevving\`.
Nothing else in that ZIP is installed (its Model Fixes and Cut Rims Restored are game files).

Hold RT in the garage to hear the car's engine rev. Nothing other players see, hear or race against: it plays in
every mode.

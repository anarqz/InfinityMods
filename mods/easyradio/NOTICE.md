# EasyRadio: attribution and scope

EasyRadio: anarqz (Infinity), https://github.com/anarqz/InfinityMods (`mods/easyradio`), GPL-3.0-or-later
(LICENSE.txt). Built from that folder's source at the commit this package was built from, with Zig's Clang.

It contains GPL-3.0-or-later code from FH Mods Collection by Bullet4fun and contributors
(https://github.com/Bullet4fun/FH_ModsCollection; Infinity's branch is this repository's
`upstream/fh-mods-collection` submodule):

- `src/easyradio.c` `install_hook`: from `install_jmp_hook_into` (`spotify-radio/spotify_bridge.c`), a 12-byte
  `mov rax` / `jmp rax` variant for 13-byte prologues;
- `src/easyradio.c` `freeze_threads` / `thaw_threads`: from `infinity_freeze_threads` / `infinity_thaw_threads`
  (`infinity/eo_plugin.c`);
- `src/easyradio.c` `game_buttons` (the controller read): from `spotify-radio/spotify_bridge.c`;
- `src/er_logo.c`: a C port of `spotify-radio/hud_logo` (`bc7.py`: BC7 modes 6 and 7; `swatch.py` /
  `make_swatch.py`: the HUD texture header, the Xbox One tiled block order, premultiplied alpha, the decode-back
  check);
- the `FH2PluginContext` layout: ExtraOptions' `fh2_plugin.h` (plugin ABI 1, GPL-3.0) by RokkuDayo,
  https://github.com/RokkuDayo/ForzaHorizon2_ExtraOptions.

`third_party/stb_image.h`: stb_image 2.30 by Sean Barrett, https://github.com/nothings/stb, public domain or MIT
(dual-licensed; the text is at the end of the file), unchanged.

`src/er_unicode_tables.h` is generated by `gen_unicode.py` from Python's `unicodedata` (Unicode data only).

No game file, or anything extracted from one, is in the source or in this package. At every game start the plugin
reads the player's own game files (the radio's `RadioInfo_<lang>.xml`) and writes the edited copies and the HUD
icons into `plugins\generated\` on the player's machine only. The music and logos are the player's own, in
`<Azimuth>\EasyRadio\`. Only the local player hears it: nothing other players see, hear or race against.
